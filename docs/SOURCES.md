## Publication boundary

Only files authored for this original product and the pinned official Three.js dependency enter the build. The source tree contains no employer manuals, private training files, screenshots or material derived from their specific parameters, internal identifiers or control schedules. No private folders were opened for this build. The site uses system fonts, performs no analytics, has no backend and sends no model state to a service. Public references are links, not uploaded reference files.
