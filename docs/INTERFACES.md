# Representative typed engine–airframe interface catalog

The catalog describes the three chosen synthetic architectures, not a universal FADEC sensor list. Active numerical loops, prescribed boundaries, inferred quantities and explanatory/monitoring paths are distinct. Electrical/service energy is not signal information. Engine control is separate from rotor flight controls and, in this chosen turboprop, from propeller speed governing.

## Reading the signals

Ng/Np and N1/N2 are model-specific shaft labels; pre-reduction speed and post-reduction rotor/prop speed are different quantities. Temperature labels identify the physical plane. Calculated T4 is not measured EGT/ITT. Pressure entries are total quantities. Fuel flow is an actuator state; equivalent FMU position is an inference. Oil/vibration/chip values are not fabricated when those circuits are outside the numerical model. Optional variable geometry, bleed and channel-fault behavior remain configuration dependent and explanatory.
